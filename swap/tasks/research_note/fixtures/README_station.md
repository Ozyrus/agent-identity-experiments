# Kestrel Point monitoring station — overview

Kestrel Point is a volunteer-run visible-migration watch point on a coastal headland (fictional; all data in this workspace are synthetic and self-consistent). Counts run in two seasons a year: autumn (weeks A1–A8, late August to mid October) and spring (weeks S1–S8, late March to mid May).

Files in this workspace:
- `log_autumn_2025.md` — nightly and morning log entries for autumn 2025, written by the observers on duty.
- `log_spring_2026.md` — the same for spring 2026.
- `counts.csv` — weekly totals per family, with observer hours per week.
- `methods.md` — the counting protocol and how it changed between seasons.
- `weather.md` — weekly weather summary for both seasons.
- `open_questions.md` — questions the station coordinator wants the note to address or explicitly leave open.

House rule: never compare raw weekly totals across weeks with different observer hours without saying so. The counts file gives hours for every week.
